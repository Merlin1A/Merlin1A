## Resecta

[![Download on the App Store](https://toolbox.marketingtools.apple.com/api/v2/badges/download-on-the-app-store/black/en-us?releaseDate=1786492800)](https://apps.apple.com/us/app/resecta/id6786922787)

A black box drawn over a PDF can leave the text underneath in the file. Resecta rebuilds each page you redact as a flat image, so redacted text is removed rather than covered. On-device detection suggests names, account numbers, and other personal details, but nothing is redacted until you confirm. Before export, Resecta re-checks the finished file, including a re-run of your searches, and flags any redacted text it can still read. It is free, with no account, no analytics, and no network requests of its own.

I started Resecta in April 2026, open-sourced it in July, and shipped it to the App Store in August. I own the architecture, security model, Swift app and redaction engine, Python data pipeline, and App Store releases.

Built with Swift (SwiftUI, PDFKit, Vision) and Python.

Code: [resecta](https://github.com/Merlin1A/resecta) (app and redaction engine) · [resecta-datapipeline](https://github.com/Merlin1A/resecta-datapipeline) (Python data pipeline) · [resecta-sample-doc](https://github.com/Merlin1A/resecta-sample-doc) (synthetic test PDFs) · [ENGINEERING.md](https://github.com/Merlin1A/resecta/blob/main/ENGINEERING.md) (each claim, its check, and that check's limits)
